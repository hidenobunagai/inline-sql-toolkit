# Security policy

Please do not disclose security vulnerabilities in public issues. Report a
vulnerability privately through the repository's configured security advisory
channel (GitHub **Security → Advisories → Report a vulnerability**) and include
the affected version, a minimal reproduction, and the impact. Do not include
secrets or personal data in the report.

The extension is designed to be offline: it does not make network requests,
connect to databases, collect telemetry, or execute formatting automatically.
Formatting starts only after an explicit command in a trusted workspace.
