# Support

For usage questions and reproducible bugs, open a repository issue. Include the
extension version, VS Code version, operating system, Python 3.12+ version, and
a small redacted example. Please remove credentials, tokens, customer data, and
other secrets before sharing source text.

Support is community-based and has no guaranteed response time. The extension
does not provide database connectivity, SQL validation, network services, or
telemetry; reports should therefore focus on the source text and formatting
options involved.
